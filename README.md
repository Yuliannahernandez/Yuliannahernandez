## Projects

### SIGEVAC — Vacation Management System
> Node.js · Express · MySQL · Vanilla JS

Institutional system for CUC that automates vacation balance calculations
based on seniority. Handles role-based access, multi-module state sync
via a centralized localStorage pattern, and complex MySQL date queries.

---

### Reelish — Cinema-Themed Food Delivery
> React · Vite · NestJS · TypeORM · Python FastAPI

Full-stack PWA with cinema aesthetics deployed on Render and Vercel.
Implements Google OAuth, 2FA with speakeasy, bcrypt authentication,
audit logging via NestJS interceptors, and data encryption with TypeORM transformers.

---

### Delphyn — Unified Student Platform
> Mobile-first UI · Glassmorphism · Market Analysis

Concept platform for CUC student services with mobile-first prototypes,
glassmorphism design, and segmented value propositions for students and professors.

---

### Sistema Reloj Marcador — Attendance API
> Node.js · MySQL · Plesk / IIS / iisnode

Attendance control API deployed on institutional shared hosting.
Includes tardiness and absence detection logic, MySQL 8.0 compatibility
fixes, and CORS configuration for IIS environments.
